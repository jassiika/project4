# Blog Website

A blog-style website built with React and React Router, featuring blog posts, a sidebar, popular posts, tags, and signup and login navigation.

Features
- Blog post cards with images and descriptions.
- Sidebar with profile information, popular posts, and tags.
- Separate Home and Dashboard pages.
- Signup form with name, email, and password fields.
- Navigation between pages using React Router.
- Reusable components for a cleaner code structure.

Tech Stack
- React
- JavaScript
- CSS
- React Router

How to Run
1. Run `npm install`.
2. Run `npm run dev` and open the local URL shown in the terminal.
